deepseek手机api版（非官方）1.1.2

本次更新：
- 新增远程热更新：应用启动后自动从 GitHub Pages 检查新版本，下载成功后提示重启生效；网络异常时继续使用内置版本，不影响正常使用。
- 内置界面已支持模型切换（deepseek-flash / deepseek-v4-pro）、思考强度调节、Token 用量与缓存命中率显示。

一、安装
1. 把 deepseek-mobile-api-1.1.2-debug.apk 传到 Android 手机（数据线、网盘或聊天工具均可）。
2. 在系统设置中允许对应文件管理器/浏览器“安装未知应用”。
3. 打开 APK 完成安装，桌面图标为蓝发鲸鱼女仆，名称为“deepseek手机api版”。
4. 首次启动后进入“设置 → 数据管理 → API Key”，粘贴在 DeepSeek 开放平台创建的 Key：
   https://platform.deepseek.com/api_keys
5. 返回首页开始对话。

四、注意

- 本项目不是 DeepSeek 官方客户端；应用名称中的 DeepSeek 仅用于说明所接入的服务与界面来源。
- API Key 由你自己提供，调用官方 API 会产生费用。
